# Adaptive Engineering Learning

通过真实项目学习工程能力：**直接讲解、自动保存断点、带语境的独立问答**。

```text
第一次：分析项目 → 提出路线 → 你确认 → 开始学习
平时：继续讲解 → 有疑问时单独问答 → 带回简短结论 → 从原断点继续
```

## 开始使用

将本仓库的 `skill-src/adaptive-engineering-learning` 目录复制到 Codex 已配置的个人技能目录，或目标项目的 `.agents/skills/` 下。已有安装时更新同名目录；项目中的学习数据留在原处。

```text
git clone https://github.com/Fui2311/adaptive-engineering-learning-skill.git
```

首次可以这样说：

```text
$adaptive-engineering-learning 带我学这个项目，先给学习路线。
```

确认路线后，直接说：

| 你说 | 它做什么 |
| --- | --- |
| 继续上次的学习 | 读取已保存断点，直接讲解，不重复初始化 |
| 这里为什么这样写？ | 结合源码回答，补齐必要基础 |
| 把这个问题单独开个问答任务 | 自动携带问题、相关讲解、代码位置与主线断点 |
| 给我一个练习，先只给提示 | 给清晰边界和验收标准，再分级提示 |
| 今天到这里 | 保存实际进展、待解问题和下一步 |

Skill 允许自动发现；是否被选中由宿主决定。由 Skill 创建的问答任务会自动带上调用方式，通常无需你再手动引入。

## 问答怎样衔接

主线中的长问答容易打断阅读；手动开任务又容易丢失“刚才这段”的语境。这个版本让代理完成交接：

1. 从当前讲解中提取相关段落和你的具体疑问，保存独立上下文包。
2. 在宿主提供任务工具时，按你的请求创建或复用问答任务，自动传入源项目和上下文路径。
3. 问答任务直接解答并保存可回看的答案；主线仅接收有用的简短结论。

普通提问不会擅自创建任务。问答记录保留当时的语境，主线后来推进也不会覆盖旧问题。不同任务使用同一源项目的学习状态，避免在新工作树中重新初始化。

没有任务工具时，会保留上下文包并给出一句带路径的启动消息，需要手动打开任务。Skill 不改变侧边栏 UI，也无法凭空知道一个空白任务想引用哪段聊天。

## 自动保存什么

- **断点**：学到哪段代码、最近相关讲解、未解问题和下一步。
- **问答记录**：独立的问题上下文与答案，可从 `.learning/dashboard.md` 回看。
- **知识笔记**：有复习价值且经过验证的解释，按主题去重；支持项目内 Markdown 和已有 Obsidian 路径。
- **掌握证据**：你自己的解释、预测、练习或诊断。助手讲过、代写完成或测试通过，不等于你已掌握。

默认先直接解释，练习时才启发式提问。只在内容实际改变时保存，不要求每次手动说“保存”，也不会把整段聊天堆进主线。

## 兼容与边界

现有 **schema v2 无需迁移**，原有任务、笔记路径和状态命令继续可用。v1 需要先说明并取得迁移许可，归档后升级。不要因调用 Skill 或打开问答任务而重建课程。

路线激活/调整需要明确确认；业务代码修改遵从你授权的范围。项目实现会被审视，缺陷与过时写法不会包装成最佳实践。

自动保存由交互触发，Skill 不是后台服务。完整的任务创建体验依赖宿主工具及对源项目路径的访问权限。
